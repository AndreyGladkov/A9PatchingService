# Установка A9 Service с перекраской под e-ink

[English version](INSTALL.md)

Сборка добавляет к A9 Accessibility Service перекраску под e-ink для каждого приложения отдельно:

- текст и иконки становятся чёрными или белыми по порогу яркости;
- фоны сводятся к чёрному, белому и светло-серому;
- для каждого приложения отдельно задаются контраст, порог чёрного и порог белого панели.

Настраивается всё в окне, которое открывается двойным нажатием кнопки E-Ink.

## Требования

| Что | Где проверялось |
|---|---|
| Hisense A9 (HLTE556N): загрузчик разблокирован, проверка vbmeta отключена | — |
| Treble GSI, пропатченный [A9PatchingService](https://github.com/damianmqr/A9PatchingService) (сервис лежит в `/system/priv-app/a9service.apk`) | LineageOS 21 GSI (Android 14, userdebug) |
| Android 10 или новее | Android 14 |
| Magisk с включённым Zygisk | Magisk 30.6 |
| Фреймворк хуков с поддержкой старого Xposed API: [Vector](https://github.com/JingMatrix/Vector) (бывший LSPosed от JingMatrix) или LSPosed | Vector v2.2 |
| Компьютер с `adb` ([platform-tools](https://developer.android.com/tools/releases/platform-tools)) и включённой отладкой по USB на телефоне | — |
| Root-доступ для `adb shell` (Magisk → Суперпользователь → Shell) | — |

## Почему установка в два этапа

Оригинальный сервис подписан ключом автора прошивки. Android не даст поставить поверх него APK с другой подписью через обычный `adb install`. Поэтому первый раз APK подкладывается в `/system/priv-app` через Magisk-модуль. Во время загрузки Android принимает новую подпись системного приложения и сохраняет его данные: режимы обновления по приложениям, назначения кнопки и прочие настройки. Последующие версии ставятся обычным `adb install -r`.

## Установка

1. **Включите Zygisk.** В приложении Magisk: Настройки → Zygisk. Перезагрузите телефон.

2. **Установите Vector.** Скачайте `Vector-*-Release.zip` со [страницы релизов](https://github.com/JingMatrix/Vector/releases). В Magisk откройте Модули → Установить из хранилища, выберите архив и перезагрузите телефон. После перезагрузки появится уведомление Vector, через него открывается менеджер.

3. **Скачайте файлы сборки:**
   - `A9Service-<версия>.apk` из релиза этого репозитория;
   - папку [`app/external_scripts/magisk_override`](app/external_scripts/magisk_override) (скрипты `install.sh`, `uninstall.sh` и `module.prop`). Можно клонировать весь репозиторий.

4. **Подключите телефон по USB** и проверьте, что `adb devices` его видит, а `adb shell su -c id` выводит `uid=0(root)`.

5. **Если раньше вы ставили обновление сервиса через `adb install`** (сервис есть в списке «обновлённых системных приложений»), сначала удалите это обновление:
   ```sh
   adb shell pm uninstall-system-updates com.lmqr.ha9_comp_service
   ```

6. **Поставьте Magisk-модуль с новым APK:**
   ```sh
   sh app/external_scripts/magisk_override/install.sh A9Service-<версия>.apk
   ```
   В Magisk появится модуль «A9 Service override». Перезагрузите телефон.

7. **Проверьте, что подмена сработала:**
   ```sh
   adb shell dumpsys package com.lmqr.ha9_comp_service | grep versionName
   ```
   Должна вывестись версия из релиза, например `3.8.1-colors.1`. Убедитесь, что служба доступности «A9 Accessibility Service» осталась включённой: Настройки → Специальные возможности.

8. **Включите модуль в Vector.** В менеджере Vector откройте Модули → «A9 Accessibility Service», включите его и отметьте приложения, которые нужно перекрашивать. Затем остановите эти приложения (Настройки → Приложения → Остановить) или перезагрузите телефон.

## Использование

- **Двойное нажатие кнопки E-Ink** открывает окно с блоком **Colors** для приложения, которое сейчас на экране:
  - **ON / OFF** включает и выключает перекраску в этом приложении;
  - **Reset** сбрасывает настройки приложения к глобальным;
  - **Text/icons** задаёт порог: всё темнее него становится чёрным, всё светлее — белым;
  - **Contrast**, **Black** и **White** — это контраст панели, порог чёрного и порог белого. Они переключаются при смене приложения.
- **Глобальные значения по умолчанию** лежат в настройках сервиса (иконка шестерёнки в окне) в категории **Colors**. Там же границы заливок и уровень светло-серого.
- **Изменения применяются сразу**, перезапускать приложение не нужно. Исключение — приложения на обфусцированном Jetpack Compose: в них часть экрана перерисуется только при следующем обновлении, например после прокрутки.

## Обновление

Новые версии из релизов подписаны тем же ключом, поэтому ставятся поверх:
```sh
adb install -r A9Service-<новая версия>.apk
```

## Откат

```sh
sh app/external_scripts/magisk_override/uninstall.sh
```
После перезагрузки вернётся оригинальный сервис. Его настройки сохранятся. Модуль в Vector можно выключить или удалить сам Vector в Magisk.

Если телефон не загружается после установки модулей, загрузитесь в безопасный режим Magisk: он отключает все модули. Если при этом работает `adb`, достаточно команды `adb shell su -c 'magisk --remove-modules'`.

## Ограничения

- **Не перекрашиваются:**
  - содержимое веб-страниц (Chrome, WebView): его рисует отдельный процесс;
  - Flutter-приложения в режиме SurfaceView, видео и игры;
  - растровые картинки без тонировки и градиенты: фото, аватары, цветные PNG-кнопки.
- **Системные «Инверсия цветов» и «Коррекция цвета» на A9 не работают.** Цветовую матрицу SurfaceFlinger применяет аппаратный блок дисплея уже после того, как e-ink контроллер забрал кадр.
- **Банковские и другие защищённые приложения** лучше не добавлять в scope Vector: они могут обнаружить хуки и отказаться работать.
- **Хуки работают только в приложениях из scope**, остальные приложения они не замедляют.

## Сборка из исходников

1. Нужны JDK 17 и Android SDK (platform 34).
2. Release-сборка подписывается ключом, который указан в `local.properties`:
   ```properties
   a9service.keystore=/путь/к/keystore.jks
   a9service.keystore.password=...
   a9service.key.alias=...
   ```
3. Соберите:
   ```sh
   ./gradlew testDebugUnitTest assembleRelease
   ```
   APK окажется в `app/build/outputs/apk/release/`.

APK, подписанный другим ключом, не встанет поверх установленного из релиза через `adb install -r`. Для него придётся повторить установку через Magisk-модуль (шаги 5–7).
