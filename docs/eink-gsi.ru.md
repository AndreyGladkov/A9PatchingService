# E-ink LineageOS 23.2 (Android 16) для Hisense A9

Образ `system` для Hisense A9 (HLTE556N) на основе LineageOS 23.2 GSI, собранный из исходников, с e-ink-доработками.

Скачать: [релиз eink-gsi-20261108.2](https://github.com/AndreyGladkov/A9PatchingService/releases/tag/eink-gsi-20261108.2) — образ `a9-eink-lineage-23.2-20261108.2.img.xz`, модуль `a9_eink_composer-v5.zip`, `SHA256SUMS`. Исходник модуля — [`magisk/a9_eink_composer`](../magisk/a9_eink_composer).

## Отказ от ответственности

Сборка сделана с участием LLM (ИИ-ассистента): код и патчи сделаны вместе с ним, я проверял их на своём A9. Это неофициальная любительская сборка, она не связана с LineageOS, Hisense или Google. Прошивка стирает данные и может оставить телефон незагружающимся. Всё предоставляется «как есть», без каких-либо гарантий: вы используете это на свой страх и риск, автор не отвечает за повреждения, потерю данных или «кирпич».

## Что нового в 20261108.2

- **VoLTE.** Звонки в LTE идут через IMS и больше не переводят телефон на время разговора в 3G, поэтому работают и там, где 3G уже отключили. Конфигурация операторов в GSI помечает VoLTE недоступным для части операторов (в том числе t2), образ снимает этот запрет. Выключить VoLTE можно переключателем в настройках SIM-карты. Проверено только на t2.

## Что нового с 2026-11-07

- **SMS и звонки в LTE.** В LTE модем A9 сам регистрируется в IMS, а в GSI не было службы IMS для Qualcomm, поэтому SMS не уходили и не приходили. Теперь в образе служба IMS из родной прошивки A9 (L2037.6.04.06.00) и точка доступа IMS. Проверено только на t2.
- **LTE разрешён по умолчанию.** Раньше чистая установка разрешала только 2G/3G.
- **Строка состояния под e-ink.** Батарея процентом; незаполненные деления сигнала — точки вместо полупрозрачных серых палок, которые e-ink превращал в «крупу».
- **Шрифт Golos Text** в интерфейсе вместо Roboto и Google Sans Flex.
- Поле поиска в Настройках сохраняет обводку 2dp и во время ввода.
- **Теплота подсветки** в плавающем меню: в A9 Service 3.8.1-colors.4 в строке Night light появился ползунок от холодного к тёплому.

## Что внутри

- LineageOS 23.2 с Google-сервисами (GAPPS), сборка 2026-11-08.
- E-ink-интерфейс из [LineageOS_gsi_HBPC](https://github.com/dianqk/LineageOS_gsi_HBPC): плоские поверхности с чёрными рамками, без анимаций, статичные жесты, экран блокировки и шторка.
- Монохромная тема по умолчанию, в том числе в мастере настройки.
- A9 Service ([A9PatchingService](https://github.com/AndreyGladkov/A9PatchingService), ветка `eink-android16-scroll-menu`): режимы обновления по приложениям, кнопки A9, подсветка, AOD, плавающее меню, Speed при прокрутке.
- Шрифт Golos Text, эмодзи монохромные (Noto Emoji): цветные на e-ink превращаются в серые пятна.
- Служба IMS для Qualcomm (`org.codeaurora.ims`) из стоковой прошивки Hisense A9 — для SMS в LTE. Её кладёт патчер из папки `stock_ims/` рядом с [`patch_system_img.py`](../app/external_scripts/system_img_patcher/patch_system_img.py); в git этих файлов нет.
- Значки строки состояния без полупрозрачных частей: оверлеи из [`system_img_patcher/overlays`](../app/external_scripts/system_img_patcher/overlays).

## Требования

- Hisense A9 (HLTE556N) со стоковым вендором Android 11 и разблокированным загрузчиком.
- Отключённая проверка vbmeta: образ не подписан AVB. Если вы уже ставили на A9 любой GSI, это сделано; если нет — один раз из fastboot: `fastboot flash vbmeta --disable-verity --disable-verification vbmeta.img` (`vbmeta.img` из стоковой прошивки).
- `adb` и `fastboot` (Android SDK Platform-Tools) на компьютере.

## Установка

**Все данные на телефоне будут стёрты**, в том числе внутренняя память. Сначала сохраните всё нужное.

1. Проверьте архив и распакуйте его:
   ```sh
   shasum -a 256 -c SHA256SUMS
   xz -dk a9-eink-lineage-23.2-20261108.2.img.xz
   ```
2. Перезагрузите телефон в fastbootd и прошейте `system`:
   ```sh
   adb reboot fastboot
   fastboot flash system a9-eink-lineage-23.2-20261108.2.img
   fastboot -w
   fastboot reboot
   ```
   Ошибка `Erasing 'cache' FAILED (Partition doesn't exist)` на A9 — норма.
3. Первая загрузка идёт около 2 минут. Затем пройдите мастер настройки.
4. **После мастера настройки один раз перезагрузите телефон**: служба IMS подключается со второй загрузки, до этого не работают SMS в LTE и VoLTE.
5. A9 Service включается сам. Если его нет в Настройки → Специальные возможности, включите его там.

Root ставится отдельно (Magisk в `boot`) и для работы сборки не нужен.

## Без моргания при смене режима

На A9 моргание при смене режима обновления делает вендорный композитор. Сборка его не меняет, поэтому без доработки вход в Speed при прокрутке и возврат из него моргают переходной волной.

Модуль Magisk `a9_eink_composer-v5.zip` берёт композитор с вашего телефона и правит в нём 14 байт: смена режима, которую помечает «Speed при прокрутке», идёт без переходной волны. Ручные переключения режимов и режимы по приложениям остаются как у вендора. Бинарников Hisense в модуле нет. Если композитор на телефоне другой сборки, модуль откажется ставиться и ничего не изменит.

1. Поставьте Magisk.
2. Magisk → Модули → «Установить из хранилища» → `a9_eink_composer-v5.zip`, перезагрузка.
3. В плавающем меню A9 Service включите **Scroll** в строке Refresh mode.

Откат: отключите модуль в Magisk и перезагрузитесь. Если экран после установки не включился, загрузитесь в безопасном режиме Magisk (зажать «громкость вниз» при загрузке): модули отключатся.

## Если не загрузилась

A9 при неудачной загрузке открывает стоковое recovery. Выбирайте только перезагрузку, **никогда не выбирайте сброс (wipe)**. Вернуться можно прошивкой прежнего образа `system` тем же способом из fastbootd.

## Обновления

Образ подписан ключом автора сборки. Следующие версии этой же сборки ставятся одним `fastboot flash system`, без `fastboot -w`, и данные сохраняются. С версий 2026-11-07 и 20261108 так и обновляйтесь; батарея останется значком, пока не выберете Настройки → Система → Строка состояния → Стиль батареи → «Текст»: это значение по умолчанию действует только на чистой установке. Переход с любой другой прошивки на эту и обратно — только со стиранием данных.
